**첨부:** refs/moa_anime_base.png, refs/moa_sheet.png

**Genspark에 먼저 붙여 넣기 ↓**
```
해설 페이지의 '프롬프트 연습 과제' 예상 결과 그림을 한 장씩 차례로 만들어 줘.
- 비율은 각 프롬프트 첫 줄을 따를 것(16:9는 가로 1920px 이상, 2:3은 세로 1536px 이상)
- 첨부한 참고 이미지의 캐릭터 외형(얼굴·머리·색·장식)을 똑같이 지킬 것
- 등장인물은 모두 20대 성인(박사는 30대 성인 남성). 노출·과장된 체형·교복 느낌·어려 보이는 얼굴 금지
- 그림 안에 글자·숫자·로고 금지(연한 회색 기준선은 허용)
- '같은 대화에 이어서'라고 적힌 그림은 바로 앞 그림을 바탕으로 적힌 것만 바꿀 것
```
