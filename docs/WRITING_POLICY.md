## 1. 목적과 독자
| 항목 | 방침 |
|---|---|
| 목적 | 얼굴을 원과 기준선에서 세우는 원리, 남녀 얼굴의 윤곽·눈·부위 높이·귀·목 차이를 실험으로 익히고, 그 기준선을 AI 얼굴 문장·가림 영역으로 옮겨 **실제 그림까지 만들어 보게** 한다 |
| 독자 | 그림과 AI를 처음 접하는 비전공자. 수식이 어려운 사람도 끝까지 읽을 수 있어야 한다 |

| 스킬 | 연구실 해설 스킬 `ai-lab-explainer-plain`(원리 먼저 교수법 P1~P7 내장)의 틀을 따른다 |

## 2. 원자료와 저작권
1. 원리는 YANAMi 『男女の顔の描き分け 角度別・年齢別・表情別のキャラデッサン』(ホビージャパン, 2018) **1장 「基本の顔を描き分けよう」(p.13~41, 정면·옆얼굴)** 을 참고한다.
2. 책의 **그림·문장·도식·구성 순서는 옮기지 않는다**. 원리만 가져와 연구실 캐릭터와 직접 움직이는 실험으로 새로 만든다.
3. 책에서 어린 인물(少女)을 예로 든 부분은 **모두 성인 캐릭터**로 바꾸고, '어려 보임'은 막아야 할 쏠림으로만 다룬다(6부 drift).
4. 원에서 머리를 짓는 법(Loomis 1956), 세 간격의 근사성(Farkas 외 1985), 가림 영역(RePaint 2022, 잠재 확산 모델 2022)은 바닥글에 출처로 적는다.
5. 원자료 출처는 목차 '원리와 출처', 바닥글, README에 모두 밝힌다.

## 4. 등장인물
- 모델: 모아(1부), 박사(2부), 시아와 박사(3부), 하루와 박사(4부), 모두(5부). 화가: 주판봇(서두르다 틀림) · 초파리(원리부터 의심해 맞힘). 평가단 X1·X2·X3(닮음·원리·자연스러움). 해설 박사, 수식 질문 조수 하루.
- **하루·시아·모아는 20대 성인, 박사는 30대 성인 남성.** 어려 보이는 얼굴·노출·교복 느낌은 쓰지 않는다.
- 외형 고정값: 하루(정수리 번 2개 + 앞머리 가운데 남색 줄), 시아(흑발, 장식 없음), 모아(흰 프릴 머리띠 + 왼쪽 귀 위 흰 리본), 박사(흰 줄 있는 짙은 머리, 굵은 눈썹, 청록 사각 안경). 표정 그림은 `fruitfly-lab-expressions`.

## 5~7. 한 부의 순서 · 단계 틀 · 문장 규칙
01편 방침과 같다. 요약하면:
- 한 부: 픽셀 표지 → 세 줄 요약 + 낱말 풀이 → 오늘의 과제 → 단계 1~4 → 프롬프트로 직접 만들어 보기 → 평가 → 정리 → 다음으로 → 지식 색인·꾸러미·바닥글.
- 단계: 제목(결과를 우리말 문장으로) → 왜 이렇게 하나 → 수식 상자(필요할 때만, **말로 하면 → 숫자 3줄 → 학교 수학 → 식 → 조각 → 한마디** 순서) → 일상/현장 → 대화 4줄 → 실험 패널 → 풀이 3줄 → 그림 → AI 결과 그대로 써도 될까? → 주의할 점 → 3지선다 퀴즈.
- 숫자는 `build/check_numbers.py`로 검산하고, 예시값은 본문과 바닥글에 예시값이라고 밝힌다.
- 우리말 어순, 사물 주어 문장(~이 만든다/정한다/말해 준다) 금지, '칸·사다리·관통' 금지, 독자를 수학·통계를 포기한 사람으로 부르는 줄임말 금지.

## 8. 프롬프트로 직접 만들어 보기
- A = `build/make_requests.py`의 프롬프트(원본), B = 'Same image. Change only: …' 한 가지 변화. 부마다 2개.
- **실제 결과**는 그림을 받은 뒤 A·B를 나란히 보고 적는다. 받기 전에는 '아직 만들지 않음'을 그대로 적는다(`content_make.py`의 `res`).
- 얼굴 일부만 고치는 실습(6부 f1)은 도구의 **부분 수정(영역 칠하기)** 기능으로 한다.

## 10~11. 실험 패널 · 연습장 · 색인
- 외부 라이브러리 없이 SVG·캔버스. `build/js_face.js`(얼굴 그리기 도구 + 패널 20개 + 연습장)를 빌드 때 `assets/panels.js`로 합친다.
- 연습장: 초록 = 환경, 파랑 = 내 결정. 미션은 직접 조작해야만 판정(`check_missions.py`).
- 페이지마다 #kg·#export, 표지·그림 현황은 `cover_manifest.json`.
